# Trin 8: to linjer i ét diagram

## Hvad vi gjorde

Når `plot()` kaldes to gange, tegnes Java og Python ved siden af hinanden.

## Kode

```python
plt.plot(reshaped_df.index, reshaped_df.java)
plt.plot(reshaped_df.index, reshaped_df.python)
```

## Hvad vi lærte

- Hvert kald af `plot()` tilføjer en linje til samme diagram.
- At sammenligne to serier på samme akser viser, hvordan Python overhaler Java i de senere år.
- Uden forklaring kan vi endnu ikke kende linjerne fra hinanden: det er næste trin.
