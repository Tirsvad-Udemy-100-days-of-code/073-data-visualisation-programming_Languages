# Mula di sini

## Persediaan dan jalankan

Cipta persekitaran maya setempat, pasang projek dan jalankan ujian:

```bash
python -m venv .venv
source .venv/Scripts/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m pytest
```

Buku nota `notebooks/programming_languages.ipynb` mengikuti sepuluh langkah. Buka dengan `jupyter lab`.
